GEMEINSAM ZEIT FINDEN

Freunde & Treffen

Teile deine möglichen freien Zeiten mit Freunden und findet einen passenden Moment. Ohne Einladung bleibt dein Plan privat. Freigegeben werden nur Zeiträume – keine Schichtnummern, Bezeichnungen, Krankmeldungen oder Stundensalden.

Meinen Plan für einen Freund freigeben

Wer deinen einmaligen Code annimmt, kann deine Zeiträume bis zum Widerruf sehen. Für jeden Freund einen eigenen Code erstellen. Eine Freigabe gilt nur in eine Richtung.

Code persönlich weitergeben. 7 Tage gültig, nur einmal verwendbar.

Einladung eines Freundes annehmen

Du erhältst Einblick in die Zeiträume deines Freundes. Dein eigener Plan bleibt privat, bis du selbst eine Einladung erstellst.

Deine Freigaben

Wann haben wir gemeinsam Zeit?

Schicht und Büro blockieren die eingetragene Zeit inklusive Puffer, auch über Mitternacht. Ruhe gilt als möglicher freier Tag. Andere Abwesenheiten und Dispo bleiben offen und werden nicht als frei vorgeschlagen. Alle Angaben beziehen sich auf die Ortszeit deiner Schichtplanung.

Mit wem? Du bist immer dabei.
